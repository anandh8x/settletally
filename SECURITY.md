# Security

SettleTally is a read-only reconciliation tool. It does not request wallet signatures, accept private keys, hold funds, or submit transactions.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could put users or infrastructure at risk. Send a private report through GitHub Security Advisories after the repository is published.

Include the affected component, reproduction steps, potential impact, and any suggested mitigation. Reports will be acknowledged as quickly as practical.

## Sensitive data

Do not include private keys, seed phrases, production invoice data, personal information, or other secrets in a vulnerability report.
